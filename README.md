# SomaOS

All-in-one operations platform for Fire and EMS departments: scheduling, time/leave/pay, personnel and credentials, training, inventory (station, medical, controlled substances), assets and fleet, forms with signatures, documents, SOGs and protocols, ePCR (NEMSIS) and fire reporting (NERIS).
